# FR-4X recordings

P1 will define and validate the JSON Lines fixture format. Do not add inferred
FR-4X mappings here. H1 requires captures from the actual instrument with its
transmission settings recorded.

The capture set must label treble notes, every bass root, major/minor/seventh/
diminished chord buttons, press/release overlaps, rapid transitions, registers,
controls, and expression. Keep each take's human label with the raw event data
so ambiguous behavior can be corrected without recapturing unrelated cases.
